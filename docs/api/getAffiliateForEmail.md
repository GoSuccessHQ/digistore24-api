# getAffiliateForEmail

Retrieves affiliate information for a specific email address.

## Endpoint

**GET** `https://www.digistore24.com/api/call/getAffiliateForEmail`

[OpenAPI spec](https://digistore24.com/api/docs/paths/getAffiliateForEmail.yaml)

## Parameters

`GetAffiliateForEmailRequest` takes the following constructor argument:

- `email` (string, required) — The email address to look up.

## Usage Example

```php
use GoSuccess\Digistore24\Api\Digistore24;
use GoSuccess\Digistore24\Api\Client\Configuration;
use GoSuccess\Digistore24\Api\Request\Affiliate\GetAffiliateForEmailRequest;

$ds24 = new Digistore24(new Configuration('YOUR-API-KEY'));

$request = new GetAffiliateForEmailRequest(email: 'affiliate@example.com');

$response = $ds24->affiliates->getForEmail($request);

echo $response->affiliateId;   // e.g. 789
echo $response->affiliateCode; // e.g. "max_mustermann"

if ($response->isActive) {
    echo $response->firstName . ' ' . $response->lastName;
}
```

## Response

`GetAffiliateForEmailResponse` exposes typed public properties:

- `result` (string) — Result status returned by the API.
- `affiliateId` (int|null) — The affiliate ID.
- `email` (string) — The affiliate email.
- `firstName` (string|null) — First name.
- `lastName` (string|null) — Last name.
- `affiliateCode` (string|null) — Affiliate code.
- `isActive` (bool) — Whether the affiliate is active.
- `commissionBalance` (float|null) — Current commission balance.
- `totalSales` (float|null) — Total sales generated by the affiliate.
- `createdAt` (DateTimeInterface|null) — Account creation date.
